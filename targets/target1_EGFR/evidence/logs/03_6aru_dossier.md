# 日誌 03 — 參考結構 6ARU 盤點（SOP §A-1 / A-2）

## 1. 6ARU 是什麼
| 項目 | 內容 |
|---|---|
| 標題 | STRUCTURE OF CETUXIMAB FAB MUTANT IN COMPLEX WITH EGFR EXTRACELLULAR DOMAIN |
| 方法／解析度 | X-ray，**3.20 Å**（分子置換，起始模型 1YY9） |
| 存放日期 | 2017-08-23（數據收集 2014-08-20） |
| chain A | EGFR 胞外域（**我們的靶點**） |
| chain B | cetuximab 突變體輕鏈 |
| chain C | cetuximab 突變體重鏈 Fab |
| chain D / E | 獨立的醣鏈（N-glycan tree：NAG/BMA/MAN） |

### 這件事的分量
參考結構**自帶一個已知結合物**（cetuximab Fab）。這等於主辦方直接把
「天然配體／已知抗體結合位在哪」交到手上 —— 對應 SOP §A-2 的表位第一選擇標準
「功能相關性」：cetuximab 的 domain III 表位與 EGF 配體結合位重疊，是**中和性（neutralising）表位**。
若 Round 2 以中和百分比計分，選這個面可讓親和力與功能兩個指標同向。

**但 SOP §C-1 另有 EGFR 專屬新穎性條款：與已知結合物相差 > 10 個胺基酸。**
判讀：該條約束的是**序列距離**，不是表位。瞄準同一個面是允許的，
前提是 VHH 序列本身與已知 EGFR 結合物（cetuximab、7D12、EgA1、9G8 等）距離足夠。
→ 列為交付給計算組的硬約束，並在最終選集前做一次序列距離檢查。

## 2. 解析度 3.20 Å 的後果（必須寫進靶點檔案）
3.20 Å 屬中低解析度。側鏈構象（尤其長側鏈 Lys/Arg/Glu/Gln）在此解析度下
擬合不確定性高。後果：
- 以側鏈氫鍵網絡為主機制的設計，其模板依據較弱
- 主鏈與大致形狀可信；**偏好形狀互補為主線**，與 KRAS 範本的結論同向（但理由不同：
  那邊是因為構象差異大，這邊是因為解析度限制）
- 若有更高解析度的 EGFR domain III 結構可用，應作為第 3–4 個修剪版本的來源（待辦）

## 4. 醣基化（SOP §A-2 必查項）
6ARU 的 LINK 記錄顯示 chain A 實際接有 N-醣鏈的位置（成熟編號）：
**ASN 328、337、389、420** —— 四個全部落在 **domain III**。
另有 NAG A 709、710 兩個單糖，以及 chain D/E 兩棵完整醣樹。
與序列 sequon 掃描（日誌 02 §3）完全一致。

### 待判定的關鍵問題（影響表位選擇，需向主辦方／規程確認）
主辦方實驗用的 EGFR（UniProt 1–645）以何種系統表達？
- 若為**哺乳類／昆蟲細胞**：醣鏈存在 → domain III 的四個醣會遮蔽部分表面，
  設計必須繞開醣鏈半徑（N-glycan 可延伸 15–25 Å），且結構裡只看得到最靠近蛋白的 1–2 個糖環，
  真實遮蔽範圍遠大於 PDB 所示
- 若為**大腸桿菌／無細胞系統**：無醣鏈 → 四個 sequon 位置變成裸露表面，
  設計用的 6ARU（有醣）與試管分子（無醣）在同一片面上系統性不一致
**兩種情況的最佳表位不同。這是本靶點最大的單一不確定性。**
暫行對策：優先選擇**距四個 sequon 都較遠**的 domain III 子面，使兩種情況下都成立。

## 6. 結論：階段 A 卡在座標
序列層級能做的已全部做完（日誌 02）。以下**全部需要真實座標**，無法再往前推進：

5. 修剪 ×3–4 版 + SHA-256 → §A-3、§A-5 的交付物本體
6. 熱點字串（BindCraft 與 RFdiffusion 兩種格式）→ §A-4、§A-5
